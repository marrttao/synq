# 1. Что делает плеер

1. Пользователь кидает аудиофайлы в папку music/ рядом с плеером. Плеер сам находит новые, удалённые и изменённые файлы (в том числе во время работы) и показывает их в библиотеке.
2. В плеере можно создавать плейлисты и добавлять треки в «Избранное». Для каждого плейлиста и для избранного на диске автоматически создаётся папка с «дубликатами» треков. Дубликаты делаются хардлинками (std::fs::hard_link), чтобы не занимать место. Если хардлинк не получился (другой диск, ошибка ФС), делается обычная копия.
3. Плеер показывает синхронизированный текст песни, если в треке есть слова. Источники проверяются по порядку:
   а) файл <имя трека>.lrc рядом с треком;
   б) текст, встроенный в теги (USLT/SYLT для ID3, LYRICS для Vorbis/FLAC и т.п.);
   в) онлайн-база LRCLIB (можно отключить в настройках);
   г) локальное распознавание через Whisper (можно отключить в настройках).
   Результат кешируется в data/lyrics/, чтобы каждый трек распознавался или скачивался только один раз.
4. Субтитры выглядят красиво: текущая строка по центру и выделена, соседние строки приглушены. Если есть таймстемпы по словам, текущее слово подсвечивается в стиле караоке. Анимации (плавное появление, прокрутка, подсветка) включаются и выключаются в настройках.
5. Пока играет музыка, можно показывать гифку. Пользователь кидает GIF, PNG или JPG в папку gifs/ и выбирает картинку в плеере: одну глобальную и, по желанию, свою для плейлиста. GIF анимируется со своими задержками кадров.
6. Работает в Windows Terminal, на обычных Linux-терминалах, в kitty и WezTerm. Если терминал не умеет показывать графику, используется фолбэк на полублоки.

# 2. Стек (фиксированный, менять только с моего согласия)

- UI: ratatui + crossterm; анимации: tachyonfx
- Воспроизведение: rodio (с декодером symphonia)
- Декодирование для распознавания: symphonia
- Ресемплинг в 16 кГц моно: rubato
- Теги и встроенные тексты: lofty
- Распознавание речи: whisper-rs, за cargo-фичей "whisper" (включена по умолчанию; без неё проект должен собираться и работать, просто без распознавания)
- Картинки: image (разбор GIF на кадры) + ratatui-image (авто-выбор протокола kitty / sixel / iTerm2 / halfblocks)
- База данных: rusqlite с фичей "bundled"
- Слежение за файлами: notify
- HTTP: reqwest (blocking, rustls) + serde / serde_json
- Конфиг: toml + serde
- Ошибки: anyhow (в приложении), thiserror (в модулях)
- Логи: tracing + tracing-appender в файл data/logs/ (никогда не писать логи в stdout — он занят интерфейсом)
- Многопоточность: обычные потоки и каналы (std::sync::mpsc или crossbeam-channel), без async-рантайма

# 3. Структура папок

Базовая папка (BASE) определяется так:
1. переменная окружения PLAYER_HOME, если задана;
2. иначе папка, где лежит исполняемый файл, если в ней есть music/;
3. иначе текущая рабочая папка (так работает cargo run).

При запуске создаются недостающие папки:

BASE/
  music/          — сюда пользователь кидает треки (плеер их только читает и никогда не удаляет)
  gifs/           — картинки и гифки пользователя
  playlists/<имя>/ — хардлинки треков плейлиста
  favorites/      — хардлинки избранного
  data/
    library.db    — база данных
    lyrics/       — кеш текстов (.lrc)
    models/       — модели whisper
    logs/
  config.toml     — настройки (создаётся с дефолтами и комментариями)

Папки music/, gifs/, playlists/, favorites/, data/ и config.toml добавь в .gitignore. Пустые music/ и gifs/ держи в git через .gitkeep.

# 4. Архитектура (модули в src/)

- main.rs — инициализация, определение BASE, логи, запуск приложения, гарантированное восстановление терминала (в том числе при панике)
- config.rs — загрузка и сохранение config.toml
- library/ — сканирование music/, чтение тегов (lofty), слежение (notify), синхронизация с БД
- db.rs — схема и миграции SQLite. Таблицы: tracks (путь, хеш или размер+mtime, title, artist, album, duration, missing), playlists, playlist_tracks (с позицией), favorites, settings
- playlists.rs — создание, переименование и удаление плейлистов, добавление и удаление треков, синхронизация папок с БД
- audio/ — поток воспроизведения на rodio: команды через канал (Play, Pause, Seek, Next, Prev, Volume, Stop), события обратно (Position, TrackEnded, Error)
- lyrics/ — парсер LRC (обычный и enhanced с таймстемпами слов <mm:ss.xx>), источники по цепочке, кеш, клиент LRCLIB
- transcribe/ — очередь распознавания в фоновом потоке, загрузка модели, whisper-rs
- visuals/ — загрузка картинок и GIF, кадры, таймер анимации, рендер через ratatui-image
- ui/ — состояние приложения, раскладка, виджеты, обработка клавиш, анимации tachyonfx

Главный цикл: UI перерисовывается примерно 30 раз в секунду, события от аудио, сканера, распознавания и загрузчика текстов приходят через каналы. UI никогда не блокируется на диске, сети или распознавании.

# 5. Детали по функциям

## Библиотека
- Поддерживаемые форматы: всё, что декодирует symphonia (mp3, flac, wav, ogg/vorbis, m4a/aac). Неподдерживаемые файлы пропускать и писать в лог.
- Если в тегах нет названия, берётся имя файла. Если нет исполнителя — «Unknown Artist».
- Если файл исчез из music/, трек помечается missing и показывается серым. Из плейлистов он не удаляется молча.

## Плейлисты и избранное
- Источник правды — БД. Папки — это её отражение.
- Добавление трека создаёт хардлинк в папке плейлиста. При совпадении имён добавляется суффикс " (2)".
- Удаление трека из плейлиста удаляет только ссылку в папке плейлиста, никогда не трогает файл в music/.
- Удаление плейлиста удаляет его папку только после подтверждения в UI.
- При старте плеер проверяет, что папки соответствуют БД: недостающее досоздаёт, лишнее не трогает, а пишет в лог.

## Тексты
- LRCLIB: GET https://lrclib.net/api/get с параметрами artist_name, track_name, album_name, duration. Использовать syncedLyrics, если есть, иначе plainLyrics. Обязательно свой User-Agent с названием плеера. Таймаут 5 секунд. Ошибки сети не должны мешать воспроизведению.
- Если текст только plain (без таймингов), показывать его прокручиваемым блоком без подсветки.
- Если источник не нашёл текст, это кешируется отдельно, чтобы не спрашивать LRCLIB заново при каждом запуске (с кнопкой «повторить поиск»).
- Пользователь может сдвигать тайминг текста клавишами (offset ±0.1 с), сдвиг сохраняется для трека.

## Распознавание (Whisper)
- Модели ggml из репозитория whisper.cpp на Hugging Face. Размер выбирается в config.toml (tiny / base / small / medium), по умолчанию base. Модель скачивается при первом использовании, с прогрессом в UI. Перед скачиванием спросить пользователя и показать размер.
- Аудио: symphonia → моно f32 → rubato 16 кГц → whisper-rs. Язык определяется автоматически, его можно переопределить в конфиге.
- Включить таймстемпы токенов, собрать их в слова, разбить на строки по сегментам.
- Защита от «галлюцинаций» на проигрышах: выбрасывать сегменты с высокой вероятностью отсутствия речи, повторы одной и той же фразы подряд и подозрительно короткие сегменты на длинной тишине.
- Сохранять результат как enhanced LRC в data/lyrics/.
- Распознавание идёт в фоне по очереди (текущий трек в приоритете), с прогрессом в UI. Музыка во время распознавания не тормозит.

## Гифки
- Масштабирование под размер панели с сохранением пропорций.
- Кадры GIF декодируются один раз и кешируются. Если гифка очень большая, кадры уменьшаются до размера панели.
- Протокол вывода картинок определяется автоматически, его можно принудительно задать в конфиге.
- Анимация гифки ставится на паузу вместе с музыкой (настраивается).

## Интерфейс
Раскладка (адаптивная, при узком окне панели сворачиваются):
- слева: Библиотека / Плейлисты / Избранное (вкладки);
- в центре: субтитры;
- справа или сверху: гифка;
- внизу: название трека, прогресс-бар, время, громкость, режимы shuffle и repeat, статус распознавания.

Режим «полный экран»: только субтитры и гифка.

Клавиши (показываются по ?):
- Space — пауза
- n / p — следующий / предыдущий трек
- ← / → — перемотка на 5 с
- + / - — громкость
- s — shuffle
- r — repeat (off / all / one)
- f — в избранное
- a — добавить в плейлист
- / — поиск
- l — включить или выключить субтитры
- g — выбрать гифку
- F — полный экран
- [ / ] — сдвиг тайминга текста
- t — распознать текст заново
- q — выход

Цветовая тема настраивается в config.toml.

# 7. Правила работы

- Не меняй стек, структуру папок и требования без моего согласия. Если что-то не получается — объясни проблему и предложи варианты.
